# vigilant-funicular

A default **Hello, World!** page celebrating the beauty of nature. 🌿

## What's inside

- `index.html` — the hello page with a full-screen mountain hero and a responsive nature photo gallery
- `images/` — nature photos used by the page

## View it

Just open `index.html` in any browser, or serve it locally:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.
